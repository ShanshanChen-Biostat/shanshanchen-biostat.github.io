# MSSS Calculator

*Multiple Sclerosis Severity Score*

The Multiple Sclerosis Severity Score (MSSS) places disability in the context of disease duration. It combines the Expanded Disability Status Scale (EDSS) with disease duration to describe relative disability severity in a reference population.

[Open MSSS calculator](https://shanshan-chen.shinyapps.io/msss-calculator/)

## Understanding the score

Disability at one point in time does not capture how long a person has been living with multiple sclerosis. MSSS considers these together, helping researchers describe disability severity relative to others with a similar disease duration.

EDSS and MSSS serve different purposes: EDSS describes disability, while MSSS contextualizes it by disease duration. MSSS is not a prediction of an individual's future disease course.

## Using the calculator

Launch the Shiny application using the link above, then follow its input labels and instructions. Consult the application's guidance when interpreting the output and reporting the calculation in research.
