# P-MSSS Calculator

*Patient-derived Multiple Sclerosis Severity Score*

The patient-derived Multiple Sclerosis Severity Score (P-MSSS) places patient-reported disability in the context of disease duration. It offers a patient-derived approach to describing relative disability severity in multiple sclerosis research.

[Open P-MSSS calculator](https://shanshan-chen.shinyapps.io/p-msss_calculator/)

## Understanding the score

P-MSSS uses patient-reported disability, commonly measured with the Patient Determined Disease Steps (PDDS) scale, together with disease duration. This differs from MSSS, which uses the Expanded Disability Status Scale (EDSS).

These disability measures are distinct; their values should not be treated as interchangeable. P-MSSS describes relative severity and is not a prediction of an individual's future disease course.

## Using the calculator

Launch the Shiny application using the link above, then follow its input labels and instructions. Consult the application's guidance when interpreting the output and reporting the calculation in research.
